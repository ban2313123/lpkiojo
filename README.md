# Temporary Portal Mod (NeoForge 1.21.1)

Мод для временного ивента с пространственной аномалией («дырой в земле»), отдельным измерением-ареной на 15 минут, сундуками, мобами, PvP и защитой арены.

## 📁 Структура папки конфигурации
При запуске сервера в папке `config/temporaryportal/` создаются:
1. `structures/` — сюда поместите файл вашей постройки (по умолчанию `arena_structure.nbt`).
2. `portal_config.json` — файл со всеми настройками таймеров, мобов, лута и координат.

## 🎮 Внутриигровые команды для настройки (Уровень прав: 4 / Оп):

### Управление событием:
* `/portal start` — Принудительно запустить портал входа прямо сейчас.
* `/portal stop` — Принудительно закрыть текущий входной портал.
* `/portal reload` — Перезагрузить конфигурацию из `portal_config.json`.
* `/portal loadstructure` — Загрузить и вставить вашу `.nbt` постройку в измерение арены.
* `/portal tparena` — Телепортироваться в мир арены для настройки точек и осмотра.

### Добавление точек (сохраняет текущую позицию игрока):
* `/portal point add entrance` — Добавить точку спавна входного портала в Обычном мире (добавьте 10 штук).
* `/portal point add exit` — Добавить точку спавна портала-выхода внутри арены (добавьте 10 штук).
* `/portal point add chest` — Добавить точку спавна сундука внутри арены.
* `/portal point add mob` — Добавить точку спавна мобов внутри арены.
* `/portal point list` — Показать количество настроенных точек.
* `/portal point clear <entrance|exit|chest|mob>` — Очистить выбранную категорию точек.

### Настройка мобов в игре:
* `/portal mob add <entityId> <name> <health> <weapon>`  
  Пример: `/portal mob add minecraft:zombie "§4Гладиатор" 50 minecraft:netherite_sword`
* `/portal mob clear` — Очистить список мобов.

### Настройка лута в сундуках:
* `/portal loot add <itemId> <minCount> <maxCount> <chance>`  
  Пример: `/portal loot add minecraft:diamond 1 3 0.5` (шанс от 0.01 до 1.0)
* `/portal loot clear` — Очистить список лута.

## ⚙️ Правила внутри Арены
1. Ломать и ставить блоки запрещено (админы с уровнем 4 могут).
2. Запрещены зажигалки, вёдра лавы/воды, костная мука.
3. Принудительный режим выживания (Survival).
4. Запрещены любые команды (кроме админов).
5. Разрешён PvP между всеми игроками, запрыгнувшими в портал.
6. Выход через портал выхода возвращает на кровать со всеми вещами.
7. Таймер 15 минут: если не успел выйти — смерть. Если погиб — респавн на кровати.

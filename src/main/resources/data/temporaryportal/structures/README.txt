# Структура арены — файл .nbt

## Как это работает

Файл `arena_structure.nbt` (в папке `config/temporaryportal/structures/`) теперь — **единственный источник данных** для арены. Из него автоматически извлекаются:

### 1. Границы арены (Bounds)
Границы вычисляются автоматически по всем блокам в структуре:
- `minX, minY, minZ` — минимальные координаты блоков
- `maxX, maxY, maxZ` — максимальные координаты блоков
- К границам добавляется отступ 5 блоков (по X/Z) и 20 блоков вверх (по Y)

### 2. Точки спавна сундуков
Поместите блоки **GLOWSTONE** (светляковый блок) в тех местах структуры, где должны появляться сундуки. После размещения структуры эти блоки автоматически удаляются (заменяются воздухом).

### 3. Точки спавна мобов
Поместите блоки **SEA_LANTERN** (морской фонарь) в тех местах, где должны спавниться мобы. После размещения структуры эти блоки автоматически удаляются.

### 4. Позиция выходного портала
Поместите блок **END_PORTAL_FRAME** (рама портала в Энд) в месте, где должен появиться выходной портал. После размещения блок автоматически удаляется.

## Создание структуры

1. Постройте арену в мире с помощью WorldEdit или вручную
2. Сохраните область как .nbt файл:
   - С помощью WorldEdit: `//sel cuboid` → `//save arena_structure`
   - Файл сохранится в `config/temporaryportal/structures/arena_structure.nbt`
3. Разместите маркерные блоки:
   - **GLOWSTONE** — где нужны сундуки
   - **SEA_LANTERN** — где нужны мобы
   - **END_PORTAL_FRAME** — где нужен выходной портал
4. Пересохраните структуру
5. Перезапустите сервер или измените конфиг для hot-reload

## Фallback (резервные варианты)

Если структура не найдена или не содержит маркеров:
- Генерируется стандартная платформа 30×30
- Используются точки из `portal_config.json`
- Если и в конфиге пусто — используются точки по умолчанию

## Пример структуры

```
                    [SOUL_LANTERN]
                    [CRYING_OBSIDIAN]
[SEA_LANTERN]  [STONE_BRICKS]  [STONE_BRICKS]  [GLOWSTONE]  [STONE_BRICKS]  [SEA_LANTERN]
                    [STONE_BRICKS]
                    [END_PORTAL_FRAME]  ← выходной портал
                    [STONE_BRICKS]
[GLOWSTONE]  [STONE_BRICKS]  [STONE_BRICKS]  [STONE_BRICKS]  [STONE_BRICKS]  [GLOWSTONE]
```

## Важные замечания

- Маркерные блоки удаляются после размещения структуры — они не останутся видимыми
- Координаты в структуре относительные (относительно `structurePlacementPos` из конфига)
- Границы арены обновляются автоматически при каждой регенерации
- Кэш структуры очищается при hot-reload конфига
